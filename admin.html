Works Admin

Upload images, videos and PDFs, edit titles, hide or delete pieces, and refresh your image sitemap. Everything is saved to your GitHub repository, and your site updates after GitHub Pages rebuilds (about a minute).

1. Connect to GitHub

How to create the tokenGitHub, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token. Choose only this repository and set Contents to "Read and write". The token stays in this browser and is sent only to GitHub. Do not share it, and delete it if you ever lose control of this device.

2. Upload new works

Drag files here, or choose them below

3. Add a YouTube video (best for large videos)

4. Library: edit, hide or delete

Files you add to a folder yourself (for example with GitHub's "Upload files") appear here too. Press Save on a row to put it on the site with a title.

5. Image sitemap

Lists every image with its title so search engines can find your work.
